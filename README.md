# NEXORA Studio — GitHub Pages release

This repository contains only the static NEXORA website export and its GitHub Pages deployment workflow. It does not contain the full application, server code, database schema, or secrets.

The site is published at `https://prathamjangra1234-dev.github.io/nexora/` when this repository is named `nexora` and the `main` branch is pushed. Contact and project-start links open an email app. GitHub Pages does not run the full app's login, client portal, admin, payments, or backend features.

GitHub Pages serves the website publicly. On GitHub Free, Pages requires a public repository; Pages is also available from a private repository on eligible paid plans.
